## [1.0.2] - 2026-10-31

### Added

- **云同步（SECTL 账户）**
  - 新增「云同步」设置页，支持同步点名历史、学生名单、清空状态与抽取统计，并提供同步状态卡片（同步中/完成/失败、上次同步时间与错误信息）。
  - 点名历史改为每设备 append-only 分片存储，记录带 uid；拉取按 uid 并集去重，重复上传与重放无副作用。
  - 新增本地 outbox，离线期间产生的记录会在恢复网络、重新登录或下次同步时补传。
  - 登录后自动初始同步：云端为空时上传本地数据；新设备首次登录以云端完整快照为基线严格覆盖；已有本地数据基线时按 uid 并集合并，并把本地独有记录补传云端。
  - 自动同步默认开启，数据变更后 5 秒防抖推送；失败按指数退避重试（最多 8 次）。登录、回到前台（5 分钟节流）与手动同步会触发同步，历史刷新会拉取云端。
  - 新增「立即同步」（先拉取合并，再推送本地变更）与「上传备份 / 从备份恢复」；备份为云端整包快照，恢复时按记录合并、不覆盖本地已有数据。
  - 账号工作区隔离：未登录使用 guest 工作区，登录后切换到按 userId 哈希命名的独立工作区；新账号从云端克隆，guest 数据不并入账号。
  - 学生名单支持跨设备同步（uid + rev 逻辑修订号合并，删除写墓碑）；清空点名历史以 clearedAt 记录跨设备同步。
  - 云端 KV 命名空间迁移到 `srlite.*`，新增设备发现注册表；旧历史记录在首次同步时派生稳定 uid 并补传一次。
- **Windows 桌面**
  - 新增点名悬浮窗：置顶显示、可拖动，支持 48–160 像素大小与预设/自定义背景色；点击悬浮窗会唤回主窗口并打开点名页。
  - 悬浮窗位置会被记住，显示器拔插或位置落在屏幕外时自动拉回可见区域；跨重启恢复上次的开关状态与外观。
  - 新增系统托盘：关闭主窗口时隐藏到托盘，托盘菜单提供「打开点名」「显示主窗口」「退出」；Explorer 重启后自动恢复图标，托盘不可用时关闭窗口直接退出。
  - 新增「登录时启动」开机自启开关：写入 HKCU Run，写入后回读注册表校验，外部修改以注册表为准。
  - 主窗口与点名悬浮窗支持位置记忆；窗口创建、显示器变化、托盘唤起时若落在屏幕外会自动拉回主工作区。
- **Android**
  - 新增控制中心「点名」快捷磁贴，点击后直达点名页；冷启动时暂存请求，Flutter 就绪后补投；适配 Android 14 的 PendingIntent 启动限制。
  - 授权回调改为 Web 跳板页 + Deep Link 返回应用，不再依赖本地 loopback 回调。
- **界面与交互**
  - 设置页新增「通用」页面，集中「不重复抽取」「点名悬浮窗」「登录时启动」；新增「云同步」页面。
  - 设置页账户入口显示头像与昵称，并随登录状态展示不同说明。
  - 历史记录页新增桌面端刷新按钮（移动端保留下拉刷新）；刷新时优先拉取云端，并提示新增记录数或回退本地记录。
  - 历史详情页新增「从云端加载历史」。
  - 数据导入完成后自动把导入的点名历史补传云端。
- **点名与抽取**
  - 新增 `DrawStats` 抽取统计模型：公平抽取只读取聚合统计，不再依赖历史记录是否完整；旧数据在首次同步迁移时从本地历史重建统计。
  - 抽取统计按设备贡献同步，云端合并视图逐项求和。

### Changed

- **设置界面**
  - 优化历史记录与设置界面的布局；相关页面限制最大宽度（1200px）并在宽屏下居中显示。
  - 宽屏设置详情默认打开「点名名单」；窄屏设置详情改为独立路由页面，返回行为与系统返回键一致。
  - 「不重复抽取」移入「通用」页面。
- **账户与登录**
  - 账户设置页改为统一的竖向流布局（最大宽度 1200px、无外层卡片）；登录等待期间显示「等待浏览器授权…」并支持取消登录。
  - 登录失败提示改为可读的中文文案（超时、取消授权、网络异常、登录失效等）。
  - OAuth 授权新增 `cloud:read` / `cloud:write` scope；`UserInfo` 兼容数字型 permission，补充开发者/贡献者字段。
  - Windows 与 Android 的 OAuth 回调改为 Web 跳板页中转，回调完成后浏览器停留在结果页，不再因本地服务关闭而显示连接被拒绝。
  - 刷新 token 增加进程级 singleflight，避免并发刷新时 refresh token 轮换导致后到的请求失败。
  - 登录成功提示与权限等级展示调整。
- **数据管理**
  - 宽屏布局改为单列列表；导出/导入范围收敛为点名历史、应用配置、学生名单。
  - 文件选择改用 `file_picker` 13 的新 API，Web 端统一通过 `readAsBytes()` 读取。
- **历史记录**
  - 清空历史时提示「其他登录同一账号的设备也会同步清空」。
  - 历史详情始终展示当前公平抽取权重。
  - 云端历史改为按 uid 自动并集合并，移除旧版同步冲突弹窗与手动选择覆盖/合并的流程。
- **点名页与配置**
  - 移除点名页竖屏控制面板的黑色阴影，`ControlPanel` 新增 `elevation` 参数。
  - 公平抽取成为唯一抽取方式，抽取记录的抽取方式固定为公平抽取（`drawMethod = 2`）。
- **其他**
  - 版本号提升至 1.0.2+13，关于页版本更新为 v1.0.2，文案改为纯点名工具。
  - Windows 主窗口只保存位置原点、不保存尺寸，避免在不同缩放比例的显示器上还原出错误尺寸。
  - 升级 `flutter_secure_storage` 至 10.3.1（自动迁移旧版 EncryptedSharedPreferences 数据）、`app_links` 至 7、`file_picker` 至 13.3。

### Fixed

- 修复云同步历史合并用截断到 50 条的内存列表整体覆写历史文件、导致本地记录丢失的问题。
- 修复关闭自动同步后仍会写入云端分片、以及重试次数在放弃后未重置的问题。
- 修复空历史分片的 `totalRecords` 返回负数的问题。
- 修复设备 ID 降级为 `unknown` 时本机统计/序号与真实分片前缀错配、可能复用 uid 的问题。
- 修复登录初始同步的覆盖原子性：先落盘数据，成功后才清空 outbox/游标；失败时保留本地待上传数据。
- 修复云端覆盖后未清空 `clearedAt`、导致后续增量拉取过滤掉刚覆盖进来的历史记录的问题。
- 修复覆盖期间并发推送/拉取可能把半覆盖状态上传云端的问题。
- 修复云端快照分片静默漏读：读取记录数与 `meta.total` 不一致时放弃快照，避免用不完整快照覆盖本地。
- 修复同步状态卡片长时间停留在旧状态、上次同步时间不更新的问题（发起、完成、异常三个时点通知）。
- 修复云端上传因 `client_id` 放在 multipart 表单字段导致 403 的问题（改为 query string）。
- 修复历史分片 outbox 的并发写入与完整性校验问题。
- 修复 OAuth 取消授权的竞态：登录 future 先挂超时，再异步打开浏览器。
- 修复 `_loadData()` 在页面 dispose 后仍调用 `notifyListeners()` 导致的偶发失败。
- 修复删除班级后的选中状态异常；删除最后一个班级后不再自动添加占位班级。
- 修复 CI 上测试偶发失败：`DataService` 新增测试数据目录覆盖点，各测试文件使用独立临时目录。

### Removed

- 移除抽奖功能：抽奖页面与底部导航/侧边导航入口、`LotteryRecord` / `Prize` / `PrizePool` 模型、`LotteryService`、抽奖设置页、抽奖历史详情页与卡片、历史标签切换组件、奖品 Excel 导入与奖品预览页。
- 清理配置、历史筛选、数据导入导出、云同步、测试与 README 中的抽奖/奖品逻辑。
- 移除「公平抽取」开关（公平抽取改为始终启用）及「抽取设置」页面。
- 移除内置默认 40 人学生名单，新工作区从空名单开始。
- 移除云同步页「同步内容」说明卡片。
- 移除账户功能 Feature Flag（`ACCOUNT_ENABLED`）与「账户功能暂未开放」占位页，账户功能默认可用。
